Chess Keeper — Help & Guide

How to Connect Two Phones / PCs (P2P Same Network)

1. Open this app on both devices and click 2-Device Link.
2. Pick My Side: White on Device 1 and My Side: Black on Device 2.
3. On Device 1, click 1. Create Invite Code and send the generated code to Device 2.
4. On Device 2, paste the code, click 2. Accept Invite & Create Reply, and send the reply code back.
5. On Device 1, paste the reply code and click 3. Complete Connection. Clocks, boards, profiles, and notation now sync live!

Epic / 2-Day Correspondence Mode (GitHub Gist)

For multi-day or untimed correspondence games, open 2-Device Link → Epic / 2-Day (Gist). Enter a shared GitHub Gist ID (and your GitHub token to push moves), then enable Auto-Pull / Auto-Push so your latest move syncs whenever you open the app.
